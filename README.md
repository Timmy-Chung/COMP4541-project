# COMP4541-project
This platform allows users to create NFT and auction the NFT. The auction format is Dutch Auction. This can prevent the NFT from being "sniped" by bot and ensure user who is willing to pay the highest price will be able to buy the NFT. This can also generate more profit for the creator, creating a win-win situation.

The contract is deployed on Sepolia testnet.
Front end can be found at: https://timmy-chung.github.io/COMP4541-project/
